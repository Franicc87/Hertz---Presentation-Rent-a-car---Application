Rent-a-Car Interactive Application
------------------------------------------------------------------------------------------------------------------------------------------------
Ova aplikacija je razvijena kao interaktivno rješenje za prezentaciju ponude rent-a-car tvrtke na tablet uređajima.
Izrađena je u React Nativeu i omogućuje korisnicima pregled videozapisa i fotografija vozila, uz intuitivno sučelje koje reagira na dodir.
Aplikacija je namijenjena korištenju u poslovnicama i promotivnim prostorima kao alat za prikaz ponude na moderan i privlačan način.
------------------------------------------------------------------------------------------------------------------------------------------------
Ključne funkcionalnosti

Prikaz promotivnih videozapisa i fotografija vozila
Interaktivni izbornik koji se otvara dodirom na ekran
Pregled osnovnih informacija o svakom vozilu
Jednostavno i pregledno korisničko sučelje optimizirano za tablete
Brzo učitavanje i responzivan dizajn
